本轮与另一个使用 MCP Gateway 的 ChatGPT 窗口进行对照测试。两边必须使用相同的权威测试定义、任务范围、验收标准和统计口径。唯一变量是工具调用通道。

## 一、执行通道与安全约束

1. 所有上游工具发现和调用必须直接使用 ChatGPT 已接入的 MCP 连接器。
2. 允许使用已接入的 GitHub、Vercel、Linear、Notion、Figma 等连接器。
3. 必须通过 `functions.exec` 调用对应工具，例如：

```js
tools.mcp__GitHub__<tool_name>(args)
tools.mcp__Vercel__<tool_name>(args)
tools.mcp__Linear__<tool_name>(args)
tools.mcp__Notion__<tool_name>(args)
```

4. 允许在 `functions.exec` 的 JavaScript 执行环境中进行合理的并发、分页、条件处理和结果归一化。
5. 严禁调用以下 Gateway 工具：
   - `mcp__mcp_gateway__search`
   - `mcp__mcp_gateway__execute_read`
   - `mcp__mcp_gateway__execute`
6. 不得通过其他间接路径调用 Gateway。
7. 全程只读，禁止任何文件、分支、PR、Issue、Project、Notion 页面或部署的创建和修改。
